Pulled from NPR's public RSS feeds. Morning Edition and All Things Considered feeds carry only their latest ten segments, so earlier segments from those shows may be missing. Summaries and topic tags are written by Claude (or keyword rules when no API key is set). Rebuilt daily by GitHub Actions. "Listen" opens the episode audio file; "On NPR" opens the story page with its player and, where available, a transcript.
